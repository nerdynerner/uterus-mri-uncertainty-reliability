Manuscript-associated implementation for assessing the reliability of machine learning error identification across uterus MRI cohorts.

Includes fixed analytical case selection and partitions, MONAI U-Net training, five-model ensemble and stochastic dropout inference, native-grid reconstruction, frozen review policies, participant bootstrap analyses, probability calibration, reference-disagreement endpoints and Figures 1-3.

The source dataset and trained weights are obtained separately. Computational provenance includes checkpoint hashes, selected epochs and measured aggregate results.
